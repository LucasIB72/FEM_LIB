\doxysubsection{Detailed Description}
Define a estrutura \doxylink{struct_element_type}{Element\+Type}, que representa um tipo de elemento finito. 

A estrutura \doxylink{struct_element_type}{Element\+Type} contém informações sobre o tipo de elemento, como a dimensão, o número de nós, os graus de liberdade por nó, o número de pontos de Gauss e ponteiros para funções que calculam as funções de forma, suas derivadas e os pontos de Gauss. \doxylink{struct_element_type}{Element\+Type} contém o que é genérico de todos os tipos de elemento, e vai instanciar elementos específicos (ex:\+ quad4). Portanto o sourcecode .c de cada tipo de elemento (ex:\+ \doxylink{quad4_8c}{quad4.\+c}) vai possuir uma função que retorna um \doxylink{struct_element_type}{Element\+Type} preenchido com as informações específicas daquele tipo de elemento.
